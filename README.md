# Audiobook Studio

Десктопное приложение для озвучки книг: загружаете **PDF**, **FB2** или **TXT**, выбираете голос и тональность, на выходе получаете **MP3**.

## Запуск (Windows)

Нужны Python 3.10+ и интернет (голоса Microsoft Edge TTS).

```bat
run.bat
```

Или вручную:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app.main
```

## Возможности

- Извлечение текста из PDF (с текстовым слоем), FictionBook 2.0 и TXT (кодировка определяется автоматически)
- Выбор языка и конкретного нейроголоса
- Пресеты тональности: нейтральный, спокойный, тёплый, светлый, драматичный, мрачный, эпический
- Ручная высота тона, темп и громкость
- Автоподстройка по тексту: восклицания, вопросы, многоточия, диалоги
- Пробное прослушивание фрагмента
- Экспорт в MP3 (обложка + дорожка AAC)

Сканы PDF без текстового слоя не озвучиваются — нужен слой текста или конвертация в TXT/FB2.
